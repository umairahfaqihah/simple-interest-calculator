# Simple Interest Calculator

A simple program that calculates simple interest based on principal amount, rate of interest, and time period.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest (per annum)
- T = Time period (in years)

## Features

- Takes principal, rate, and time as input
- Calculates and displays the simple interest
- Displays the total amount (Principal + Interest)
